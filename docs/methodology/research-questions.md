# 研究问题与假设

## 研究问题

### RQ1 · 政策工具如何影响要素配置

生产性补贴、收入性补贴、保险补贴、土地流转激励这几类工具，分别如何影响农户的：

- **种植结构**（粮作 vs 经济作物面积占比）；
- **要素投入**（化肥、机械、保险的投入强度）；
- **劳动力配置**（"务农 / 务工"的兼业选择）。

### RQ2 · 微观机制与异质性

政策通过哪些微观机制起作用？重点关注三条路径：

- **风险预期路径**：保费补贴降低风险规避农户的保守倾向，是否提高其高价值、高波动作物与规模经营意愿；
- **收益比较路径**：直补改变"种粮 vs 务工""粮作 vs 经济作物"的相对收益，是否改变种植与兼业选择；
- **流动性约束路径**：流转补贴缓解离农的流动性约束，是否促进土地集中与劳动力再配置。

对不同**经营规模、年龄、风险偏好**的农户，效应是否不同？（异质性检验）

### RQ3 · 政策组合的权衡

政策组合能否在**粮食安全**（播种面积）与**农户增收**之间取得平衡？工具之间存在哪些权衡，财政成本分别是多少？
（粮食安全指数 vs 增收指数的 Pareto 前沿）

## 可检验假设

| 假设 | 内容 | 对应情景 |
| --- | --- | --- |
| H1 | 提高粮食直补强度 → 提高粮食播种面积占比，对"粮经比"敏感的小农更明显 | `grain_subsidy` |
| H2 | 保费补贴 → 降低风险厌恶农户的保守种植倾向，提高高价值、高波动作物与规模经营意愿 | `insurance_subsidy` |
| H3 | 流转激励 → 土地向种粮大户集中，提高规模化与单产，但可能短期加剧小农离农 | `land_transfer_subsidy` |
| H4 | 单纯增收工具可能挤压粮食面积，"补贴+保险+流转"组合才可能兼顾安全与增收 | `combined` |

## 假设的可识别性

每个假设都绑定一个可独立施加、可量化的政策工具（`set_subsidy` / `set_insurance_subsidy_rate` /
`set_land_transfer_out_subsidy`），并通过分阶段反事实把"政策前 / 政策后"的差异归因于该工具，
控制个体异质性（同批农户）。详见 [识别策略](/methodology/identification)。

## 理论框架

- 风险下农户生产决策模型
- 计划行为理论（TPB）
- 政策工具理论
- 反事实推断（潜在结果框架）

> 这些理论为"为什么政策会影响行为"提供机制解释，也为 [实验设计](/methodology/experimental-design) 中
> 的农户画像维度（风险态度、资产、兼业）与机制检验（决策日志质性编码）提供依据。
