# 研究方法总览

> 赛道：**数智公共管理与国家治理**（AI 社会科学家研究挑战赛）　方向：**农林经济管理**
> 完整版研究计划见仓库 `research-plan.md`（v2，2026-08-20）。

## 一句话定位

把"农户"建模为带真实偏好、风险态度与家庭约束的 LLM 智能体，放在一个可标定的村庄农业经济环境里，
逐个施加不同涉农政策冲击，通过可重复、可干预的反事实模拟，估计政策对种植结构、农户收入与粮食安全的影响，
形成"政策实施前的沙盒评估"。

## 为什么做这件事

农业政策正从增产导向转向保供给、促增收、可持续的多重目标（粮食直补、保险保费补贴、流转激励、生态补偿等），
但政策落地前缺少低成本、可迭代的效应评估手段。传统两条路各有天花板：

- **事后计量**：政策已落地，只能观测已发生结果，做不了反事实对照，农户行为变化难干净识别；
- **CGE / 一般均衡模型**：能推演宏观效应，但行为人高度同质，装不下心理账户、风险态度与家庭约束。

AgentSociety² 提供带情感/需求/动机/认知的社会人智能体、可干预的社会环境、以及回放与统计分析，
对"强异质性、强情境依赖"的农户决策问题，比固定规则 ABM 更能还原人在具体处境里的权衡，且天然支持反事实实验。

## 研究问题与假设

**研究问题（RQ）**

- RQ1：生产性 / 收入性补贴、保险补贴、流转激励，分别如何影响种植结构、要素投入与"务农/务工"劳动力配置？
- RQ2：政策通过哪些微观机制起作用（风险预期、收益比较、流动性约束）？对不同规模 / 年龄 / 风险偏好的农户效应是否不同？
- RQ3：政策组合能否在粮食安全（播种面积）与农户增收之间取得平衡？工具间存在哪些权衡，财政成本各多少？

**可检验假设（H）**

| 假设 | 内容 |
| --- | --- |
| H1 | 提高粮食直补强度 → 提高粮食播种面积占比，对"粮经比"敏感的小农更明显 |
| H2 | 保费补贴 → 降低风险厌恶农户的保守种植倾向，提高高价值、高波动作物与规模经营意愿 |
| H3 | 流转激励 → 土地向种粮大户集中，提高规模化与单产，但可能短期加剧小农离农 |
| H4 | 单纯增收工具可能挤压粮食面积，"补贴+保险+流转"组合才可能兼顾安全与增收 |

详细拆解见 [研究问题与假设](/methodology/research-questions)。

## 实验设计要点

- **农户智能体**：行为实验模式（观察 → LLM 决策 → ask_env 提交工具），异质画像（区域/规模/风险/资产/兼业/年龄/教育）；
- **政策环境**：观测 / 生产决策 / 政策干预 / 复盘四类工具，逐季核算并回放；
- **政策情景**：baseline + grain_subsidy + insurance_subsidy + land_transfer_subsidy + combined；
- **反事实识别**：分阶段（基线阶段 → 施加政策 → 政策阶段），同批样本控制异质性；
- **可复现**：固定种子、分情景分重复落库、记录模型版本与温度。

完整设计见 [实验设计](/methodology/experimental-design)；识别逻辑见 [识别策略](/methodology/identification)。

## 对评审标准的回应

| 评审维度 | 本研究的安排 |
| --- | --- |
| 社会科学价值 | 直面粮食安全与农民增收的政策议程，输出可操作的事前评估工具 |
| 研究问题创新性 | 用可执行社会模拟做政策沙盒，区别于事后计量与 CGE |
| 方法设计严谨性 | 反事实情景对照 + 重复实验 + 异质性 + 机制检验 + 全链路可复现 |
| 科学发现与理论贡献 | 揭示政策工具权衡与异质性机制，形成机制性发现 |
| 研究影响与拓展潜力 | 参数可标定，可扩展其他涉农政策与地区，产出可复用实验基础设施 |
