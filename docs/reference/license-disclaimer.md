## 免责声明

1. **科研沙盒原型**：本仓库代码与数据均为科研沙盒原型，用于"政策实施前的沙盒评估"探索，
   不构成任何真实政策建议。
2. **参数为示意值**：`configs/economics.json` 中的作物单产、价格、成本、保费、租金、灾害阈值等
   **均为示意值**，不代表任何真实地区的农业经济参数。真实结论须以标定后的参数、平台运行数据与统计推断为准。
3. **结论定位**：模拟是受控实验，输出应定位为"机制性启示"而非"因果估计"。外部效度有限，
   不能直接外推到真实政策效果。
4. **异质画像**：农户画像由统计分布生成，不代表任何具体个人或群体，论文中声明抽样逻辑，避免刻板印象。
5. **学术诚信**：代码与智能体工作区随作品提交，并明确说明 AI 在流程中的角色。
6. **平台依赖**：本项目依赖 [AgentSociety²](https://agentsociety2.readthedocs.io/zh-cn/latest/index.html)
   （清华 · 计算社会科学与国家治理实验室），其使用须遵守对应平台的许可与服务条款。

如将本项目用于正式研究或政策分析，请先完成参数标定、敏感性分析，并在成果中注明数据来源与方法边界。
